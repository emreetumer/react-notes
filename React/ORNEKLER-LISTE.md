## 💡 Nasıl Kullanılır?

### Örnekleri Çalıştırmak:

1. **React projesi oluştur:**
```bash
npx create-react-app my-app
cd my-app
```

2. **Örneği kopyala:**
- İstediğin örnek dosyasını `src/App.jsx` içine kopyala

3. **Çalıştır:**
```bash
npm start
```

### Router Örnekleri İçin:
```bash
npm install react-router-dom
```

Sonra `index.js`'de BrowserRouter ile sarmala:
```jsx
import { BrowserRouter } from 'react-router-dom';
root.render(
  <BrowserRouter>
    <App />
  </BrowserRouter>
);
```
