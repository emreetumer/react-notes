## 💡 .NET Developer'dan React Developer'a

.NET'ten geliyorsan, şu benzerlikleri göreceksin:
- **Components = Classes/Methods**: Yeniden kullanılabilir parçalar
- **Props = Method Parameters**: Dışarıdan veri alma
- **State = Class Fields/Properties**: İç veri yönetimi
- **JSX = Razor Syntax**: HTML benzeri syntax
- **Hooks = LINQ benzeri**: Fonksiyonel yaklaşım

Hadi başlayalım! 🚀
